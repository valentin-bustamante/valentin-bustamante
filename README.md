## Selected projects

### S-otify · Music discovery application

A collaborative academic project with a separate frontend and backend.

- **Frontend:** Search and filter a song catalog, play audio, view song details, and manage favorites. Includes account registration and login, Spanish/English translations, and component tests.
- **Backend:** REST API for songs, authentication, and user favorites, with PostgreSQL persistence through Prisma.

**Stack:** React · Tailwind CSS · i18next · Vitest · Node.js · Express · PostgreSQL · Prisma · JWT

[Frontend repository](https://github.com/bgastong/S-otify) &nbsp;·&nbsp; [Backend repository](https://github.com/luquitas45/s-otify-backend)

**Stack:** React · JavaScript · CSS Modules · Vite
